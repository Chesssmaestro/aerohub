# Выкладка на VPS (Beget, Ubuntu 26.04)

Сервер: 2 ядра, 2 ГБ, 30 ГБ NVMe, публичный IPv4. Домен — `aerohub24.ru`.

Как устроено на сервере:

| Что | Где |
|---|---|
| Код сайта | `/opt/aerohub` |
| База | `/opt/aerohub/aerohub.db` |
| Файлы заказов | `/opt/aerohub/media/` |
| Настройки (ключ, админ, код сотрудников) | `/etc/aerohub.env` |
| Сайт (uvicorn) | служба `aerohub`, порт 8000 только изнутри сервера |
| Веб-сервер и HTTPS | nginx + бесплатный сертификат Let's Encrypt |

Всё ставит скрипт `deploy/install.sh`, а `deploy/upload.ps1` отправляет сайт на сервер с вашего компьютера.

## 1. Создать сервер

1. Beget → VPS → конфигурация **2 ядра / 2 ГБ / 30 ГБ**, система **Ubuntu 26.04**,
   **Публичный IPv4 — включён**.
2. После создания в панели будут **IP-адрес** и **пароль root** — они понадобятся ниже.

## 2. Направить домен на сервер

В DNS домена `aerohub24.ru` (Beget → Домены → DNS) создайте две **A-записи** на IP сервера:

| Имя | Тип | Значение |
|---|---|---|
| `@` (сам домен) | A | IP сервера |
| `www` | A | IP сервера |

Обновление DNS занимает от 5 минут до нескольких часов. Можно не ждать и сразу переходить
к шагу 3: без DNS сайт встанет, а HTTPS включится командой из шага 5.

## 3. Выложить сайт

На своём компьютере откройте PowerShell в папке проекта и выполните (подставьте IP сервера):

```powershell
powershell -ExecutionPolicy Bypass -File deploy\upload.ps1 -Server 111.222.333.444
```

Что произойдёт:

1. Первое подключение спросит `Are you sure you want to continue connecting?` — введите `yes`.
2. Пароль root спросят дважды (копирование и установка) — вставьте пароль из панели Beget.
   При вводе он не отображается, это нормально.
3. Скрипт на сервере поставит Python, nginx и certbot (2–4 минуты) и задаст вопросы:
   - **Почта администратора** — Enter оставит `admin@aerohub.ru`;
   - **Пароль администратора** — от 8 символов, без кавычек, `\` и пробелов;
   - **Код приглашения для сотрудников** — Enter создаст случайный, скрипт его покажет. Запишите.
4. В конце: `Готово: https://aerohub24.ru`.

Если DNS уже обновился, HTTPS включится сам. Если нет — скрипт так и напишет, см. шаг 5.

## 4. Проверить

- Откройте `https://aerohub24.ru` (или `http://IP-сервера`, пока DNS не обновился).
- Войдите на `/login` почтой и паролем администратора из шага 3.
- Пароль можно сменить в профиле: `/staff/profile`.

## 5. Включить HTTPS, если на шаге 3 не получилось

Когда домен начнёт открываться по `http://aerohub24.ru`, подключитесь к серверу и выполните:

```
ssh root@IP-сервера
certbot --nginx --redirect -d aerohub24.ru -d www.aerohub24.ru
```

Сертификат продлевается сам (certbot ставит таймер).

## Обновление сайта

После правок в коде — та же команда, что и в шаге 3:

```powershell
powershell -ExecutionPolicy Bypass -File deploy\upload.ps1 -Server IP-сервера
```

Вопросы про администратора больше не задаются. **База, файлы заказов и настройки не трогаются** —
заменяется только код, сайт перезапускается за пару секунд.

## Полезные команды на сервере

```
systemctl status aerohub          # работает ли сайт
journalctl -u aerohub -n 100      # последние записи журнала (ошибки)
systemctl restart aerohub         # перезапуск
nano /etc/aerohub.env             # настройки; после правки — systemctl restart aerohub
```

`AEROHUB_ADMIN_EMAIL` и `AEROHUB_ADMIN_PASSWORD` в `/etc/aerohub.env` используются только
при самом первом запуске, пока в базе нет пользователей. Дальше пароль меняется в профиле.

## Резервные копии

Beget делает автобэкапы сервера. Всё ценное — в двух местах: `/opt/aerohub/aerohub.db`
и `/opt/aerohub/media/`. Скачать копию базы себе:

```powershell
scp root@IP-сервера:/opt/aerohub/aerohub.db .\aerohub-backup.db
```

## Проверить локально перед выкладкой

```
.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
```

`render.yaml` остался от прежнего варианта на Render и для VPS не нужен.
